    Recorrido en el autómata

    Actual en negro · visitados en amarillo pálido · última transición en ocre. Para seguirlo con calma, elige un recorrido lento o paso a paso: cada transición se muestra por separado, con el token que la provoca (resaltado en la cinta) y la pila que deja.

      Pulsa Validar para obtener el veredicto, o Validar por bloques para ver cómo el autómata lee el documento y mueve su pila.

      El árbol muestra qué producciones de la gramática generan el texto. Con textos de más de 250 tokens no se dibuja.

      Mide el documento actual con el autómata de pila y con la línea base, que construye el árbol completo (serde_json) y lo valida (jsonschema). Con XML la línea base solo construye el árbol (roxmltree): no hay un validador de XSD comparable, así que hace menos trabajo que el autómata. Cada ronda aparece en cuanto termina.

      Más documentos de ejemplo para la inferencia

      Convertir el esquema pasa un XSD a JSON Schema o un JSON Schema a XSD. Inferir deduce un esquema a partir del documento (y de los ejemplos de arriba, si los hay). Convertir el documento pasa el documento de XML a JSON o al revés, guiado por el esquema.

      Convención XML ↔ JSON: un elemento con atributos o hijos es un objeto; cada atributo es la propiedad "@nombre", cada hijo la propiedad con su nombre y el texto junto a atributos, "$". Un hijo que puede repetirse es siempre un arreglo. Lo que el otro lenguaje no puede expresar aparece en los avisos.
